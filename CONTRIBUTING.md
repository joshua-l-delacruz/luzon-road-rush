# Contributing

Thank you for helping improve Luzon Road Rush.

1. Open an issue describing the bug or focused change.
2. Fork the repository and create a short-lived branch.
3. Keep artwork and audio original or appropriately licensed.
4. Run `npm test` and `npm run build`.
5. Submit a pull request explaining behavior changes and verification.

Please keep gameplay accessible by keyboard and touch, avoid collecting player data, and add tests for deterministic rules. Security issues should be reported privately according to [SECURITY.md](SECURITY.md), not in a public issue.
